# DATA-REGISTER

Railway-first business management system for transactions, accounts, heavy-material inventory and monthly P&L.

## Development phases

1. Foundation & Railway setup
2. Business / branch / account structure
3. Transaction engine
4. Cash & bank management
5. Heavy material inventory
6. Stock locations & history
7. Daily material usage
8. Monthly P&L
9. Monthly closing
10. Reports
11. Dashboard & analytics
12. Security & production hardening

## Deployment

This project is designed for **Railway + GitHub**. Vercel is not required.

Railway should detect the Node/Next.js project from `package.json` and run the production build automatically.
